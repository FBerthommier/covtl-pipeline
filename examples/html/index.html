self-contained pages (no server, no network): open directly from the file system

The COVTL polar planning model drives the tongue body toward targets in a mid-sagittal polar space (ρ, θ). Two dissociated gestures are superposed: the vocalic branch zv (red, always active, anchor-to-anchor arcs and vowel plateaus) and the consonantal branch zc (blue, active during the consonant clusters, looping through the consonant node targets). Each demo animates the mid-sagittal vocal tract, the polar figure and the branch trajectories, synchronized with the synthesized audio — the interactive counterpart of the dual-panel MP4 (examples/polar_demo_en.mp4).

Controls

  • space play / pause · ← / → step ±10 ms (shift: ±100 ms) · home / end jump to the boundaries
  • scrub with the timeline slider, or click / drag directly on the ρ / θ traces chart
  • speed 0.25× / 0.5× / 1× (audio-rate), loop and mute toggles

How it is built

Everything is embedded at generation time: the .polar v4 trajectories (100 Hz, two branches + phoneme inventory), the sagittal frames (SVG polylines from vocaltractlab_cython.tract_state_to_svg, 25 fps) and the synthesized audio (AAC data URI, the playback master clock). The canvas rendering mirrors vtl_synth/video/polar_video.py (render_polar_frame): display curvature K=30 (ν=+1) for the vocalic arcs and K=10 (ν=−1) for the consonantal sub-arcs — the reference planning geometry of arXiv:2307.02299 §2.1, not the quasi-rectilinear SYL_K=1000 parameter arcs used by the synthesis engine.

Regenerate after changing the pipeline or the demo phrases:
